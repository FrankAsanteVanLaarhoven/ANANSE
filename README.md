# ANANSE: Kingdoms of the Story Road

A local single-player greybox and content-authoring prototype for a mythic West African social-stealth adventure. The campaign follows Kwaku, the Story-Binder. Ananse is a separate character identity.

**Status — 14 October 2026:** the existing Linux game now has an opt-in episode runtime: New Game, opening/subtitles, three infiltration routes, played pursuit, both consequences, real sanctuary map travel, draft epilogue, completion and versioned checkpoints. Six route/outcome combinations reached saved completion in packaged gameplay. Kwaku remains the campaign character; Ananse remains a separate eight-appendage **engineering proxy**. This is not a finished 15–20-minute production episode: final art, sound, presentation, mobile qualification and online services remain incomplete. See the [current content-integration evidence and limitations](docs/production/EPISODE_CONTENT_PROGRESS_2026-10-14.md).
