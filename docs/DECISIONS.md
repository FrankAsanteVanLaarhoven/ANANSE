# Initial architecture decision record

ADR-001: single-player Android-first slice; co-op/competitive economy are later independently tested scope.
ADR-002: UE 5.8 family plus exact local Build.version lock; no auto-upgrade or assumed newest preview.
ADR-003: strict versioned authoring metadata, immutable release snapshots and build-time game import; no database credentials or runtime code generation in the client.
ADR-004: local FastAPI/SQLite to prove authoring contracts; production SSO/PostgreSQL/asset workers are deliberately not simulated by flags.
ADR-005: original young Kwaku separate from Ananse, paid cultural review, no exclusive claim over inherited folklore.
ADR-006: baseline mobile forward/stylised authored lighting, no general mobile dependency on Nanite or Lumen.
ADR-007: small deterministic social rules before generative conversation; no live LLM authority over progression.
ADR-008: tests report their actual domain. HTTP is not browser, Python is not Unreal, compiling is not playing, packaging is not device or store validation.
ADR-009: credentials, binaries, paid assets and user workstation changes are not bundled or performed implicitly.
